# CU-07 — Schedule therapy session

**Primary actor:** Therapist

## Basic flow

1. The Therapist searches for the Patient by identityDocument.
2. The system checks that the Patient is active.
3. The system obtains the standard duration of the Therapy.
4. The system schedules the Session with its date.
