The problem

A Shopper submits product codes, quantities and an optional coupon. The system reads trusted catalog prices and returns the subtotal, discount and payable item amount, or an explicit refusal. The example is read-only and requires no external service.

Run it locally

From the repository root, Python's standard library runs the validators and reference tests. Add --render to regenerate SVG/PNG using PlantUML installed locally.

python3 examples/order-pricing/09-reference-implementation/run_example.py
python3 examples/order-pricing/scripts/verify.py
python3 examples/order-pricing/scripts/verify.py --render

The README explains execution, review boundaries and each stage's artifacts. This offline reader uses embedded diagrams and requires no CDN or hosted renderer.
